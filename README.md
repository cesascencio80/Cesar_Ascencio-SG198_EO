# Metallic Electro-Optic Effects in SG198 Topological Chiral Crystals

This repository accompanies the manuscript:

**“Metallic Electro-Optic Effects in Topological Chiral Crystals”**  
C. O. Ascencio, D. J. P. de Sousa, and Tony Low

The repository will contain electronic band structures and electro-optic response data for the 37 nonmagnetic materials belonging to space group 198 examined in the manuscript.

## Data

For each material, the repository will include:

- Relativistic electronic band structure
- Energy-dependent Berry curvature dipole $\mathbf{D}$
- Energy-dependent gyrotropic magnetic tensor $\mathbf{K}$
- Energy-dependent magnetoelectric electro-optic tensor $\mathbf{G}$
- Energy-dependent electric Drude tensor $\mathbf{V}$
- Fermi-level tensor coefficients
- Critical electric fields $E_{0c}^{E}$ and $E_{0c}^{B}$

## Status

This repository is currently under construction. Data will be added material by material.
